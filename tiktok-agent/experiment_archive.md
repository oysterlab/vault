# Experiment Archive

전략이 어떻게 진화하며 스코어를 높여왔는지 추적하는 전체 기록.
모든 변화의 출처를 구분하여 기록한다.

## 출처 태그

| 태그 | 의미 |
|------|------|
| `[EXPERIMENT]` | experiment.md를 통해 주입된 인스턴트 실험 |
| `[SCOUT]` | Scout 에이전트의 경쟁 분석에서 도출된 시도 |
| `[SELF]` | Planner가 메트릭 데이터 기반으로 자체 발견/수정한 전략 |

## 형식
```
### #{번호} [태그] — {제목} ({날짜})
- 출처: {어디서 온 아이디어인지}
- 가설: {뭘 테스트했는지}
- 방법: {어떻게 했는지}
- 결과:
  - 포스트 A: {score} ({접근법}) — {tiktok_url from status.json}
  - 포스트 B: {score} ({접근법}) — {tiktok_url}
  - 포스트 C: {score} ({접근법}) — {tiktok_url}
  - 기존 평균: {score}
- 판정: ✅ 전략 흡수 / ❌ 폐기 / ⚠️ 추가 검증 필요
- 근거: {왜 이 판정인지, 구체적 데이터}
- 반영: {strategy.md에 뭘 바꿨는지, 또는 "변경 없음"}
```

포스트 URL은 content/status.json의 tiktok_url 필드에서 가져온다.
